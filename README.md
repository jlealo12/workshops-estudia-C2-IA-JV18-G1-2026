## Descripción
Este repositorio contiene los notebooks y materiales utilizados en el curso de Inteligencia Artificial Intermedio de EstudIA 2026. 

## Opciones de ejecución
- **Local**: Puedes clonar este repositorio y ejecutar los notebooks en tu entorno local. El repositorio utiliza uv como gestor de entornos virtuales. Para instalar las dependencias, ejecuta el siguiente comando en la raíz del proyecto:
```bash
uv sync
```

- **Google Colab**: Puedes abrir los notebooks directamente en Google Colab haciendo clic en el siguiente enlace: [Abrir en Colab](https://colab.research.google.com)
